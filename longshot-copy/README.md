# 长图直贴 1.0.0

点击 Chrome 工具栏图标，截取网页长图并自动复制为 PNG。默认不主动滚动，不打开结果预览页、不自动下载。

## 安装

在 Chrome 打开 `chrome://extensions`，启用「开发者模式」，点击「加载已解压的扩展程序」，选择本文件所在、包含 `manifest.json` 的文件夹，然后固定工具栏图标。无需安装其他依赖。

请保留此文件夹。更新文件后，在扩展管理页重新加载扩展，并刷新已打开的网页。

## 使用

在普通网页点击图标，保持当前页面和 Chrome 在前台。看到「已复制」后，在支持图片的应用中按 `⌘V`（Mac）或 `Ctrl+V`（Windows）。成功提示约 0.8 秒关闭。

小叉号或 `Esc` 可取消截图。内部滚动区可右键图标选择「滚动兼容截图（页面会移动）」，结束后恢复原位置。

## 隐私与限制

扩展在本机处理当前网页和截图，不上传图片，不保存浏览历史，不读取已有剪贴板。截图可能包含页面上的个人信息；图片复制后由系统剪贴板和接收粘贴的应用管理。准备截图可能加载原网页自己的图片资源。

默认模式使用 Chrome 调试权限；任务结束断开连接，Chrome 自身的调试提示保留。固定页头、粘性栏和动画可能短暂调整，所以不保证截图过程完全无感。

只处理当前已加载的页面内容。无限滚动、虚拟列表、折叠、分页以及跨域框架的内部内容不保证完整。Chrome 内页、扩展商店、PDF 浏览器和本地文件暂不支持；超大图片会等比例缩小。

要求 Chrome 116 及以上，推荐最新版；实际验证环境为 macOS / Chrome 157，其他系统和真实旧版浏览器尚未实机验证。
