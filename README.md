# 长图直贴

一个轻量的 Chrome 扩展：点击工具栏图标，截取网页长图并自动复制为 PNG，随后直接粘贴到支持图片的聊天、文档或笔记软件中。

- 默认不主动滚动当前网页。
- 截图后自动复制，不打开结果预览页，不自动下载。
- 简洁进度条，复制成功后显示本次耗时，约 0.8 秒关闭。
- 截图时隐藏浏览器滚动条，避免长图右侧出现重复滑块。
- 提供手动选择的滚动兼容模式，适配主要内容位于内部滚动区的页面。
- 本地处理，无账号、广告、统计追踪或截图上传。

扩展本身没有第三方运行依赖，不需要编译。作者：**Mob**。许可证：[MIT](LICENSE)。

## 安装

要求 Chrome 116 或以上，推荐使用最新版。

1. 下载本仓库 Releases 中的 `longshot-copy-1.0.0.zip` 并解压。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
4. 将「长图直贴」固定到工具栏。

也可以下载仓库源码，安装时选择其中的 **`longshot-copy` 子文件夹**。安装不需要运行 npm 命令。

请保留安装用的文件夹。更新时替换文件，在扩展管理页点击重新加载，并刷新此前打开的网页。GitHub 分发版不会通过 Chrome 扩展商店自动更新。

## 使用

在普通网页上点击扩展图标，保持当前标签页和 Chrome 在前台。看到「已复制」后，在支持图片的软件里按 `⌘V`（Mac）或 `Ctrl+V`（Windows）。

小叉号和 `Esc` 可取消截图；点击面板外关闭提示不会主动取消任务。取消或失败不会显示为成功。成功提示只在实际复制完成后出现，随后一秒内淡出关闭。

若提示主要内容位于独立滚动区，可右键工具栏图标，选择「滚动兼容截图（页面会移动）」。该方式会滚动页面或主要内容区域，结束后恢复原位置；长页通常比默认模式慢。

## 使用边界

- Chrome 会短暂显示自身的调试提示条；扩展不会隐藏它。默认模式不主动滚动，但提示条、固定页头、粘性栏和动画的临时调整可能影响截图过程中的可见画面，不能保证完全无感。
- 截取当前已加载的内容，并尝试加载原生懒加载图片。虚拟列表、无限信息流、分页、折叠内容和跨域框架内部内容不能保证完整。
- Chrome 内部页、扩展商店、PDF 浏览器及本地文件暂不支持。
- 过大的图片会等比例缩小。切换标签页、离开 Chrome 或调整窗口大小可能停止截图。
- 打开当前页的开发者工具可能与默认截图冲突；可关闭后重试，或手动使用兼容模式。

实际验证环境为 macOS / Chrome 157。旧版复制分支通过模拟验证；真实旧版 Chrome、Windows 和 Linux 尚未完成实机验证。

## 隐私与权限

仅在你主动点击截图时访问所选网页。处理的内容包括当前页 URL（判断页面是否支持）、布局、滚动位置和截图。网页中显示的个人信息也可能进入图片，请按需要选择截图内容。

扩展不上传截图，不读取浏览历史数据库、Cookie 或现有剪贴板，也不保存截图历史。临时图片在任务结束时清理，复制结果由系统剪贴板保留；系统剪贴板历史、同步及接收粘贴的应用由它们各自管理。准备截图可能加载原网页的图片资源。

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 临时访问用户主动选择的当前标签页 |
| `scripting` | 测量和准备页面，完成后恢复临时样式 |
| `debugger` | 默认模式直接截取整页，并隐藏截图中的滚动条；任务结束断开连接 |
| `clipboardWrite` | 将生成的 PNG 写入剪贴板 |
| `offscreen` | 为部分 Chrome 版本提供本地合成和复制的后备环境 |
| `contextMenus` | 在工具栏图标右键菜单中提供滚动兼容截图 |
